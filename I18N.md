# GRAM-X Internationalization & Localization (i18n)

## 1. Supported Languages
- **English (`en`)**: Primary administrative language.
- **Hindi (`hi`)**: Devanagari script rural-first interface.
- **Tamil (`ta`)**: Dravidian localization.
- **Telugu (`te`)**: Telugu regional localization.

## 2. Architecture & Translation Keys
- Translation dictionaries reside in `frontend/src/i18n/locales/`.
- Access via `useLanguage()` hook and `t('key.name')`.
- Voice accessibility supports dual-mode Hindi/English speech recognition.
