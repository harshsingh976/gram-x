## 🔐 Security & Cryptographic Guarantees

1. **AES-GCM PII Vault & Blind Indexing**: Citizen mobile numbers and personal identity data are encrypted at rest (`enc::...`). Queries are resolved without decryption via HMAC-SHA256 blind indexing tokens.
2. **Cryptographic SHA-256 Hash Chain**: Every state transition, payout, and evidence verification is cryptographically linked into an immutable block-by-block ledger with active tamper verification.
3. **Capability-Based & Resource-Scoped RBAC**: Prevents horizontal and vertical IDOR across all 4 authoritative roles:
   - **🏘️ Citizen**: Own grievances only (`CAP_CREATE_COMPLAINT`, `CAP_VERIFY_RESOLUTION`)

## ☁️ Deployment on Render (One-Click Blueprint)

GRAM-X includes a native **`render.yaml`** configuration blueprint for zero-config deployment on [Render.com](https://render.com).

### Render Blueprint Architecture
- **Backend Web Service**: Python FastAPI running on Gunicorn/Uvicorn with health check probes at `/api/health/ready`.
- **Frontend Static Site**: Vite + React single-page application with automatic SPA routing rewrites (`/* -> /index.html`) and backend API proxy routing.

### Quick Deploy Steps:
1. Connect your GitHub repository to Render.
2. Click **New** $\rightarrow$ **Blueprint**.
3. Select this repository; Render will automatically parse `render.yaml` and provision:
   - `gramx-backend` (Python Web Service)
   - `gramx-frontend` (Vite Static Site)
4. Set environment variables if using custom database connections (defaults to resilient SQLite + Polyglot store).
